# 圆桌终端

版本 `0.1.1`

圆桌终端是一个面向 Windows 的像素风行情图表工作台。界面使用 Rust、eframe、egui 和 wgpu 构建，所有窗口、按钮、菜单、输入框、滚动条、图表和软件指针都由 Painter 逐像素绘制。

## 特性

- 强制 1 逻辑点等于 1 物理像素，不使用系统缩放。
- `GRID = 8px`、`LINE_W = 1px`、`PITCH = 9px`，静态布局对齐 9px 网格。
- 主窗口由标题栏、菜单栏、窗口区、任务栏和状态栏组成，最外侧为占一格 `9px` 的装饰边框。
- 默认使用浅色主题，可在运行时切换深色主题。
- 最多同时打开 32 个独立图表窗口；关闭后再次新增会复用原窗口和独立 Pane，不会共享缩放、平移或十字光标状态。
- 子窗口支持移动、逐像素缩放、独占、置顶、最小化、最大化和关闭。
- 独占窗口和置顶窗口互斥；独占时隐藏置顶按钮，置顶时隐藏独占按钮。
- 非置顶独占窗口与非置顶普通窗口双向碰撞，接触后共用 1px 边框并可沿边滑动。
- 窗口最小化后进入任务栏，支持分页、标题区还原和按落点排序。
- 任务栏“圆桌”按钮与最小化项目区之间保留两个单元格，边框只保留两侧竖线。
- 软件鼠标使用 1:1 位移和零附加加速度，指针图片统一缩放为 `31px * 31px`，定位点固定在图片中心。
- 内置 K 线、美国线、成交量、MACD、KDJ、RSI、BOLL、OBV、CCI、BIAS 指标。
- 图表支持滚轮缩放、鼠标拖动平移、十字光标和指标脚本实时刷新。
- 指标代码编辑器支持 `#` 注释、用户自定义名称着色、输入法、撤销、查找、剪切、复制和粘贴。
- 调试控制台提供运行状态、滚动日志和命令输入。
- 主题、指标脚本、图标、指针和窗口符号都从 `assets` 目录运行时加载。

## 运行

环境要求：

- Windows 10/11 x64
- Rust 1.85 或更高版本
- MSVC 工具链
- 支持 wgpu 的显卡驱动

开发运行：

```powershell
cargo run
```

发布构建：

```powershell
cargo build --release
Copy-Item -Recurse -Force assets target\release\assets
```

项目不使用自定义构建脚本。字体在运行时从 `assets/fonts`、Windows 字体目录或当前目录加载。

## 基本操作

- 单击窗口标题栏或窗口内容后，该窗口成为焦点。
- 拖动普通窗口标题栏可移动窗口；拖动内侧 8px 边框带可缩放窗口。
- 单击标题栏系统按钮可独占、置顶、最小化、最大化或关闭窗口。
- 最大化窗口铺满窗口区，最大化期间不能移动或缩放。
- 双击普通窗口标题栏可最大化，单击最大化窗口标题栏可还原。
- 任务栏最小化项目可通过标题区单击还原，也可拖动标题区调整顺序。
- 右键窗口区空白处打开主上下文菜单。
- 主窗口空白处拖动不会框选或移动子窗口。

## 图表

- 图表区左侧固定显示“切换”和“代码”按钮，不显示指标名称文字。
- “切换”打开内置指标列表。
- “代码”打开当前图表对应的指标源码编辑器。
- 指标代码窗口可从四边和四角缩放，最小内容尺寸为 `cells(40) * cells(30)`。
- 鼠标滚轮围绕指针位置缩放，左键拖动绘图区横向平移。
- 每个图表窗口拥有独立的 Pane、指标对象、视图范围和脚本状态。
- 达到 32 个图表窗口后不再新增，并在状态栏显示限制提示。

## 主题

默认主题：

```text
assets/themes/light.json
```

备用主题：

```text
assets/themes/dark.json
```

启动时加载浅色主题。通过控制面板或调试控制台 `theme` 命令切换主题时，会重新读取目标 JSON。主题文件缺失或校验失败时使用内置配色，不影响程序启动。

右键菜单、顶部菜单下拉和图表指标菜单都带一圈占一格 `9px` 的装饰边框。

主题 JSON 使用语义化颜色分组：

- `application`：标题栏、菜单栏、工作区、任务栏和状态栏
- `window`：窗口内容、面板、边框、分隔线和符号
- `controls`：按钮、输入框、滚动条、提示框和调色板
- `editor`：编辑器正文、行号、注释、自定义名称和边框
- `chart`：绘图区、坐标轴、十字光标、状态字段和涨跌色
- `indicators`：内置指标线颜色
- `pointer`：软件指针轨迹颜色

## 指标脚本

系统脚本位于：

```text
assets/scripts
```

用户修改后的指标保存到 `userdata`，不会覆盖系统脚本。编辑器中的“还原原始指标代码”会重新读取当前指标的系统脚本。

脚本支持与图表绘制共用的颜色、线宽、K 线类型、柱状图空心状态、状态栏字段、时间轴和纵轴策略。

## 资产目录

```text
assets/
  cursors/    软件指针
  fonts/      可选字体文件
  icons/      编辑器图标
  logo/       应用图标
  scripts/    指标脚本
  symbols/    窗口与任务栏符号
  themes/     主题 JSON
```

图标和符号使用 PNG，主题和脚本在运行时读取。用户数据写入 `userdata`。

## 架构

- `ChartWorld` 保存行情、Pane 和指标组件，仅负责行情与图表局部 ECS。
- `WinMgr` 管理窗口顺序、焦点、布局、任务栏、独占碰撞和生命周期。
- `StockApp` 管理主题、菜单、编辑器、控制台、软件指针和帧级交互。
- 窗口、菜单和交互不进入全局 ECS。
- 系统关闭、最小化、最大化、独占、置顶和分页按钮统一使用 `17px * 17px` 图标。
- 状态栏最左侧固定显示时间，FPS 字段固定贴住状态栏最右侧。
- 同类控件复用统一的 Painter、主题字段和按钮对象。

主要模块：

```text
src/app.rs                 应用状态与帧循环
src/ecs/                   行情与图表局部 ECS
src/indicator/             内置指标
src/script.rs              指标脚本
src/ui/chart.rs            图表绘制与交互
src/ui/winmgr.rs           窗口管理
src/ui/menu.rs             菜单栏与弹出菜单
src/ui/editor.rs           指标代码编辑器
src/ui/icon.rs             图标、软件指针与 PNG 解码
src/theme.rs               主题加载与调色板
```
