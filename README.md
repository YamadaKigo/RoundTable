# RoundTable

## System Requirements

Runtime environment:

- Windows 10 or Windows 11, x64.
- Access to the program directory for reading `assets` and writing `userdata`.

Build environment:

- Rust `1.85` or later.
- Cargo.
- MSVC toolchain.
- Windows SDK.

The project uses the Rust 2024 Edition.

The application has no third-party crate dependencies.
