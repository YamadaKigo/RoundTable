<h1 align="center">RoundTable 圆桌</h1>

<p align="center">一个坚持 1 逻辑点 = 1 物理像素、界面全部由 Painter 手绘的 Windows 行情图表工作台。</p>

RoundTable 使用 Rust、eframe、egui 与 wgpu 构建。窗口、菜单、按钮、输入框、滚动条、图表和指针都由纯色矩形与 1px 线条逐像素绘制，不使用圆角、阴影、渐变、透明混色或抗锯齿。

项目当前包含随机游走行情、K 线/美国线/宝塔线/收盘线、成交量、MACD、KDJ、RSI、BOLL、OBV、CCI、BIAS、指标代码编辑、浮动子窗口和调试控制台。行情与图表面板使用局部 ECS 数据层，窗口、菜单、布局和交互使用普通 UI 状态结构；主题、指标脚本、界面符号和位图资源都放在可替换的资源目录中。

## 当前特性

- 无边框全屏主窗口，客户区铺满窗口。
- 强制 1 逻辑点等于 1 物理像素。
- 9px 界面节距：`GRID = 8px`、`LINE_W = 1px`、`PITCH = 9px`。
- 默认打开深色主题，可切换到浅色主题。
- 中文使用宋体 16px 点阵，ASCII 使用 Fixedsys 8x16 点阵，字形保持 1bpp 硬边。
- 图表 ECS：只覆盖行情、面板组件、渲染缓存和指标计算，不把 UI 强套进 ECS。
- 每个图表独立保存缩放、平移、可见范围和十字光标状态。
- 鼠标滚轮围绕指针位置缩放，左键拖动图表横向平移。
- 子窗口支持拖动、自由尺寸缩放、独占、置顶、最小化、最大化和关闭。
- 主窗口由标题栏、菜单栏、窗口区、任务栏和状态栏组成；子窗口只在窗口区活动，最小化窗口排列在任务栏。
- 任务栏左侧为“圆桌”菜单按钮，菜单按钮与最小化项目之间保留两个单元格的带边框留白；右侧为上一页/下一页符号按钮；最小化项目超出可用宽度时自动分页，标题栏区域可以左右拖动调整顺序。
- 控制面板默认置顶但不独占，初始位于窗口区右下角；指标代码窗和调试控制台默认置顶；颜色面板默认置顶，并与其他子窗口处于同一层级。
- 非焦点子窗口禁用鼠标和键盘输入，悬停可见区域后转移焦点。
- 只有处于独占状态的窗口才产生独占碰撞；非置顶独占窗口与非置顶普通窗口双向互斥，拖动碰撞会沿边缘滑行，并共用 1px 边框线。未独占窗口之间允许自由重叠。
- 独占互斥只阻止矩形内部重叠，不会封锁独占窗口所在的整行或整列。
- 图层从下到上固定为非置顶独占、非置顶普通、置顶三层；置顶窗口不受独占互斥影响。
- 主窗口空白处拖动不会产生框选，也不会选中或移动子窗口。
- 指标使用通达信风格公式代码，编辑后立即解析并刷新图表。
- 用户指标保存为独立副本，不覆盖 `assets/scripts` 中的系统脚本。
- 单实例运行，重复启动不会打开第二个主程序。
- 像素级自动化测试覆盖布局、字距、主题、滚动条、脚本、焦点和交互。

## 运行环境

- Windows 10/11 x64。
- Rust 1.85 或更高版本，使用 2024 edition。
- MSVC 工具链。
- 支持 wgpu 的显卡驱动。

项目使用 eframe 的 wgpu 后端。若在虚拟机或远程桌面中出现渲染问题，请先更新显卡驱动，或确认系统支持 DirectX 12/Vulkan。

## 快速开始

```powershell
git clone <你的仓库地址>
cd RoundTable
cargo run
```

调试构建会从仓库的 `assets/` 目录读取资源。发布版可以这样构建：

```powershell
cargo build --release
Copy-Item -Recurse -Force assets target\release\assets
.\target\release\RoundTable.exe
```

资源目录优先在可执行文件旁查找 `assets/`；找不到时会回退到编译时记录的仓库路径。源码运行无需复制资源，分发时必须随 exe 一起复制完整的 `assets/`。

## 界面与操作

### 主窗口

- 启动后直接进入全屏，初始工作区默认只显示控制面板，不创建图表窗。
- 窗口移动、子窗口拖动和边缘缩放都由应用逐帧处理。
- 菜单栏包含文件、数据、分析、布局、工具、帮助。布局菜单可打开控制面板或新增图表；其余菜单项目前作为界面占位，点击结果写入状态栏。
- 右键工作区空白处可新增图表、打开调试控制台、切换主题，或打开编辑器快捷菜单。
- 任务栏最小化项目的标题栏区域可以左右拖动，释放后按落点重排顺序；置顶、还原、关闭按钮仍保留各自点击行为。
- 任务栏项目超过可用宽度时使用右侧上一页、下一页按钮翻页，排序只在当前可见页内完成。

### 图表

- 鼠标滚轮：围绕指针位置缩放 K 线。
- 鼠标左键拖动：横向平移。
- 悬停在图表上：显示十字光标，以及索引、价格和时间标签。
- 图表标题栏：左上角显示指标名称，右上角依次为“圆桌”、切换指标、打开当前图表的指标代码；“圆桌”按钮当前仅保留入口。
- 图表底部状态栏：显示缩放、平移和可见根数。

### 子窗口

- 拖动标题栏移动窗口。
- 只有鼠标落在左、右、下边缘或右下、左下角的 1px 边框线上才能连续缩放；共享边框归当前焦点窗口。
- 普通子窗口未置顶时标题栏按钮依次为独占、置顶、最小化、最大化/还原、关闭；置顶后隐藏独占按钮，解除置顶后恢复。
- 颜色面板默认置顶，和最小化标题条一样只提供置顶、最小化/还原和关闭。
- 颜色面板的色相条与 RGB 滑块都按 1px 连续移动，不按 9px 网格跳格。
- 只有处于独占状态的窗口参与独占碰撞；未独占窗口之间可以自由重叠。独占窗口与非独占窗口拖动、缩放时会停在同一条 1px 边框线上，并可沿边滑动。
- 窗口与一个或多个独占窗口重叠时，完整离开全部重叠区后才恢复独占碰撞约束。
- 窗口最大化直接铺满工作区，不受独占窗口影响；最大化期间禁止改变尺寸，点击其标题栏只还原窗口，不启动拖动。
- 最大化还原和任务栏还原都回到操作前的位置与尺寸。
- 除控制面板外，新窗口默认出生在窗口区正中央，不向下堆叠；关闭窗口后再次打开仍重新居中出生。
- 双击普通窗口标题栏最大化，点击最大化窗口标题栏还原，点击任务栏窗口标题还原。
- 同一时刻只有一个焦点激活窗口，只有最近操作过的焦点激活窗口可以开始改变尺寸。
- 窗口接触独占窗口时停在同一条 1px 边框线上，不产生 2px 边框堆叠。
- 主窗口空白处拖动不会框选多个窗口，也不会移动窗口。
- 下拉菜单绘制在当前窗口最上层，并限制在该窗口矩形内。

### 控制面板

控制面板默认置顶但不独占，初始位于窗口区右下角，当前按钮为：

| 按钮 | 作用 |
| --- | --- |
| 重新生成 | 更换种子，重新生成一段随机行情 |
| 设置涨色 | 打开调色板修改上涨色 |
| 设置跌色 | 打开调色板修改下跌色 |
| 切换鼠标控制 | 在软件鼠标与系统鼠标之间切换 |
| 鼠标轨迹 | 显示最近一段轨迹、速度、加速度和坐标 |
| 重置视图 | 把当前图表缩放和平移恢复初始值 |
| 切换主题 | 在深色与浅色主题之间切换 |
| 图表配色跟随系统 | 让涨跌色重新跟随当前主题 |
| 新增图表 | 新增图表窗，最多 8 块 |
| 打开调试控制台 | 打开运行状态、日志和命令输入窗口 |
| 打印当前状态 | 把图表、窗口、主题和视图状态写入状态栏 |

图表缩放只通过鼠标滚轮完成。控制面板不提供放大、缩小、鼠标速度加减或鼠标加速度加减按钮。

### 调色板

- RGB 与 HSV 色块、输入框和滑块都由 Painter 手绘。
- 可拖动滑块把手，也可直接点击轨道定位。
- 鼠标位于 RGB 或 H 滑块条内时，滚轮可按横向方向移动滑块。
- 应用后立即刷新对应图表的涨色或跌色。

## 主题

默认主题：

```text
assets/themes/dark.json
```

备用主题：

```text
assets/themes/light.json
```

主题文件是运行时真源。启动时加载深色主题；通过控制面板按钮或调试控制台 `theme` 命令切换时，会重新读取目标 JSON。文件缺失、JSON 语法错误、字段缺失或颜色格式非法时，程序会输出错误并回退到内置配色，不会阻止启动。

### 主题文件格式

主题文件必须包含以下顶层字段：

```json
{
  "format": "roundtable-theme",
  "version": 1,
  "id": "dark",
  "name": "深色",
  "colors": {
    "window": {},
    "chart": {},
    "indicators": {},
    "pointer": {}
  }
}
```

字段规则：

- `format` 固定为 `roundtable-theme`。
- `version` 当前固定为 `1`。
- `id` 必须与文件名一致：`light.json` 使用 `light`，`dark.json` 使用 `dark`。
- `name` 是给主题文件阅读者看的说明字段，不能为空。
- 所有颜色必须是 `#RRGGBB`。
- 所有字段都是必填项；未知字段会报错，避免拼写错误被静默忽略。

## 指标代码

每个内置指标对应一份运行时可编辑脚本：

```text
assets/scripts/
  candle.rti
  bars.rti
  volume.rti
  macd.rti
  kdj.rti
  rsi.rti
  boll.rti
  obv.rti
  cci.rti
  bias.rti
```

图表标题栏的“代码”按钮打开当前图表的指标代码。编辑器修改会实时解析并应用到当前图表，不执行 `cargo check` 或编译命令。语法错误时保留上一版图形，并在状态栏显示错误原因。

系统指标位于 `assets/scripts`。编辑器保存时不会修改这些文件，而是写入：

```text
userdata/indicators/paneN_xxx.rti
```

`userdata` 用于存放用户自定义内容，已加入 `.gitignore`。打开指标代码时优先加载该面板已有的用户副本；编辑器工具栏从左到右为“新建、保存、剪切、复制、粘贴、撤销、查找”文字按钮，“新建”会清空为空白文件，文件菜单中的“还原原始指标代码”可重新读取系统脚本。

### 基本变量

| 变量 | 含义 |

| `O` | 开盘价序列 |
| `H` | 最高价序列 |

### 函数

| 函数 | 用途 |
| --- | --- |
| `MA(X,N)` | N 周期简单平均 |
| `EMA(X,N)` | N 周期指数平均 |
| `REF(X,N)` | 向前引用 N 根 |

| `STD(X,N)` | N 周期总体标准差 |
| `HHV(X,N)` / `LLV(X,N)` | N 周期最高 / 最低 |

| `ABS(X)` | 绝对值 |
| `IF(条件,真值,假值)` | 条件选择 |
| `CROSS(A,B)` | A 上穿 B |

### 绘图命令

| 命令 | 用途 |
| --- | --- |
| `CANDLE(上涨色,下跌色,线宽)` | 蜡烛线，参数均可省略 |
| `OHLC(上涨色,下跌色,线宽)` | 美国线，参数均可省略 |
| `PAGODA(上涨色,下跌色,线宽)` | 宝塔线，参数均可省略 |
| `CLOSE(上涨色,下跌色,线宽)` | 收盘线，参数均可省略 |
| `VOL(上涨色,下跌色,空心,线宽)` | 成交量柱，参数均可省略 |
| `LINE(X,颜色,线宽)` | 折线 |
| `HIST(X,颜色,空心,线宽)` | 以零轴为基线的柱，同一颜色 |
| `HIST(X,上涨色,下跌色,空心,线宽)` | 按正负值使用不同颜色的柱，可用于 MACD 红绿柱 |
| `HLINE(X,颜色,线宽)` | 水平线 |
| `ZERO(颜色,线宽)` | 指标零轴，参数可省略 |

### 显示与样式配置

| 命令 | 作用 |
| --- | --- |
| `STATUS_SHOW(0/1)` / `STATUS_HIDE()` | 显示或隐藏状态栏；`STATUS(0/1)` 是兼容写法 |
| `TIME_SHOW(0/1)` / `TIME_HIDE()` | 显示或隐藏时间轴；`TIME(0/1)` 是兼容写法 |
| `AXIS_SHOW(0/1)` / `AXIS_HIDE()` | 显示或隐藏纵轴；`AXIS(0/1)` 是兼容写法 |
| `AXIS_FIXED(V1,V2,...)` | 纵轴固定显示给定刻度，并按这些刻度确定范围 |
| `AXIS_AUTO(0/1)` | 纵轴按当前指标数据动态计算刻度，参数决定是否包含零轴 |
| `AXIS_DYNAMIC()` | `AXIS_AUTO(0)` 的兼容写法 |
| `AXIS_ZERO()` | 动态刻度并显示零轴 |
| `STATUS_FIELD("标签",变量,颜色,"0.00")` | 在状态栏显示变量；不传颜色时使用文字色，不传格式时使用 `0.00` |

`LINE`、`HLINE` 可追加线宽：`LINE(X,COLOR(0x3366CC),3);`。
`HIST` 和 `VOL` 可追加空心与线宽：`HIST(X,AUTO,1,2);`、`VOL(UP,DOWN,1,2);`。
`HIST` 使用 5 个参数时分别为数值、上涨色、下跌色、空心和线宽：`HIST(DIF-DEA,UP,DOWN,1,2);`。
颜色可直接写 `0xRRGGBB`、裸 `#RRGGBB` 或字符串 `"#RRGGBB"`，也可用 `SYSTEM_COLOR(UP)` 指向系统配色、
`COLOR(0xRRGGBB)` 或 `RGB(51,102,204)` 指定自定义颜色。裸 `#RRGGBB` 只有后面正好是 6 位十六进制颜色时才按颜色解析，其余 `#` 行仍按注释处理。

赋值使用通达信风格冒号：

```text
DIF: EMA(C,12)-EMA(C,26);
DEA: EMA(DIF,9);
HIST(DIF-DEA,AUTO);
LINE(DIF,DIF);
LINE(DEA,DEA);
ZERO();
```

自定义状态栏、坐标带和完整柱状图样式：

```text
STATUS_SHOW(1);
TIME_SHOW(1);
AXIS_AUTO(1);
DIF: EMA(C,12)-EMA(C,26);
DEA: EMA(DIF,9);
HIST(DIF-DEA,UP,DOWN,1,2);
LINE(DIF,#3366CC,2);
LINE(DEA,SYSTEM_COLOR(DEA),1);
HLINE(0,SYSTEM_COLOR(ZERO),1);
STATUS_FIELD("DIF",DIF,SYSTEM_COLOR(DIF),"0.00");
STATUS_FIELD("DEA",DEA,#CC9900,"0.00");
```

颜色可使用 `AUTO`、`UP`、`DOWN`、`TEXT`、`ZERO`、`DIF`、`DEA`、`K`、`D`、`J`、`RSI1` 到 `RSI3`、`BOLL_MID`、`BOLL_UP`、`BOLL_DOWN`、`OBV`、`CCI`、`BIAS1` 到 `BIAS3`、`MA1` 到 `MA6`、`EMA1` 到 `EMA6`，也可使用 `0xRRGGBB` 或 `#RRGGBB`。编辑器支持 `#` 行注释。

## 图表 ECS 架构

### Entity

`Entity` 是轻量、可复制、可比较的稳定标识。每个图表面板实体都拥有独立 ID，组件表按实体顺序保存对应组件。

### Component

当前核心组件包括：

- `Pane`：指标对象、指标脚本、绘图指令缓存、绘图区高度和脏标记。
- `Crosshair`：十字光标数值、序号、浮点位置和所属面板。
- `ChartView`：单个图表自己的缩放、偏移、可见根数、平移、滚轮余量和十字光标。
- `MarketBars`：行情序列资源，提供只读切片访问与整体替换。

`ComponentTable<T>` 将实体 ID 与组件值分开保存，并通过 `Deref`、索引和迭代器提供低开销访问。

### Resource

`ChartWorld` 只保存图表域共享资源：行情序列、行情种子、面板实体表和当前指标调色板。

### System

- `mark_panes_dirty`：数据、指标或配色变化后统一置脏。
- `ensure_pane_computed`：只对脏面板执行指标计算并更新绘图指令。
- `regenerate_market`：替换行情资源并让全部面板重算。

`StockApp` 使用普通字段保存窗口管理器、焦点、菜单、任务栏、编辑器、图表面板高度和颜色偏好，并通过 `Deref`/`DerefMut` 只借用 `ChartWorld` 的图表数据。这样 ECS 只出现在实体数量多、缓存和指标计算明确受益的图表域，UI 状态保持直接、可预测和低开销。

## 绘制约束

这些约束由代码和测试共同维护：

- 静态控件宽高使用 `cells(n) = 9n + 1`。
- 静态骨架、控件和文字落点对齐 9px 网格。
- 子窗口位置、子窗口尺寸、滑块、滚动条和图表绘图区允许按 1px 连续移动。
- 每块子窗口拥有自己的坐标原点，窗口内元素按该原点排版。
- 靠右和靠下的元素按固定像素跟随窗口边，不重新吸附网格。
- 所有窗口、控件和区域边框只允许 1px。相邻或接触的边框必须重叠为同一条 1px 线，禁止任何 2px 边框堆叠。
- 相邻控件共用 1px 线；区域分割线在内容之后补画，避免被内容覆盖。
- 自由尺寸产生的余量进入弹性段，使用 `free_band` 与 `free_tail` 一类入口处理。
- 只使用 1px 横线和竖线，不使用圆角、阴影、渐变、透明混色和抗锯齿。
- 下拉菜单属于当前窗口最上层，整块限制在该窗口矩形内。
- 只有处于独占状态的窗口参与独占碰撞；非置顶独占窗口与非置顶普通窗口双向互斥，未独占窗口之间可以自由重叠。碰撞按轴分离，接触边缘后保持滑行并共用 1px 边框。
- 置顶窗口不受独占互斥影响；已重叠的非置顶窗口先完整离开全部独占区，再恢复碰撞约束；最大化直接铺满工作区，不受独占窗口阻挡。
- 主窗口空白处不提供框选，子窗口标题栏动作只作用于当前窗口。
- 标题栏空白区使用 1px 底纹模板，当前默认隔 1px 画一条横线，颜色来自主题 `title_fill`。
- 悬停提示统一记录到 `StockApp::tooltip`，在整帧最后绘制。
- 全局文字只能通过 `StockApp::text` 绘制，横向落点只使用 `text_left_x` 与 `text_right_x`。
- 用户界面文本只使用中文与 ASCII。
- 文本编辑区域内的鼠标指针始终为文本指针，只有滚轮和右键操作可以临时改变指针状态。

## 扩展指南

### 新增指标

1. 在 `src/indicator/` 新建指标文件并实现 `Indicator`。
2. 在 `src/indicator/mod.rs` 注册到 `builtin()` 和需要的 `default_layout()`。
3. 若需要专属颜色，扩展 `Palette`、`Theme` 与主题 JSON，并同步更新文档。
4. 增加指标数值与绘图指令测试。

### 新增核心数据

先判断它属于实体组件还是世界资源：

- 每个实体各有一份：新增组件类型并放入 `ComponentTable<T>`。
- 图表实体共享且需要跨系统读取：放入 `ChartWorld`。
- 每次数据换代都需要重算图表：通过 `mark_panes_dirty` 或新系统统一处理。
